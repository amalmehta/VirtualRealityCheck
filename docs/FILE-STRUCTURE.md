# File Structure

| Path | What it is |
|---|---|
| `index.html` | The page, dialogs, security policy and formula |
| `css/style.css` | All styling: light and dark, opening animation |
| `js/app.js` | Screens, routing, input, settings, import and export |
| `js/measures.js` | All content: questions, directions, sources, suggestions, limits |
| `js/scoring.js` | Pure calculations: parsing, over the line, surprise, verdicts, comparison |
| `js/store.js` | Saving, loading and validating data |
| `js/chart.js` | The strip chart |
| `js/sample.js` | The invented person behind the sample result |
| `js/theme.js` | Applies your saved theme before first paint |
| `assets/` | Icon and self-hosted fonts |
| `scripts/render-icons.mjs` | Renders the icon to PNG |
| `tests/*.test.mjs` | Unit tests |
| `tests/flow.e2e.js` | Browser tests on sample runs |
| `docs/` | Instructions, system design, this file, prompt log, review checklist, screenshots |
| `VirtualRealityCheck.md` | The project spec, with definitions and decisions |
